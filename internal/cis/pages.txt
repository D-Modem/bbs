:CIS-162 HELP COMMANDS ?
=CompuServe
 T - TOP menu page
 M - previous MENU
 H or ? - HELP
 GO word or GO page - GO directly to a service
 FIND topic - FIND all references to topic
 OFF or BYE - sign off
 LOG - sign off and log on again
 R - RESEND a page
 F - FORWARD a page
 B - BACK a page
 N - display NEXT menu item
 P - display PREVIOUS menu item
 SET option - SET terminal option
   SET BRIEF ON|OFF, SET PAGED ON|OFF, SET WIDTH n, SET LINES n

 Commands may be chained with ";" (GO RATES;T).
 ^C abandons a line or a display, ^U erases a line, ^V retypes it.

:NEW WHATSNEW
=What's New
 This CompuServe service runs on this BBS, sharing its users.  You
 log on with your BBS name or your User ID (shown at logon) and your
 BBS password.

 Here now: the menus and articles, GO words and FIND, and the
 terminal settings of SET.

 On their way, in this order: forums (the BBS's message areas, with
 the forum command language), libraries and the CompuServe B and
 B Plus protocols, CompuServe Mail, the CB Simulator, and the
 CompuServe Information Manager (CIM) graphical service.

:RATES CHARGES BILLING NEWBIL
=CompuServe
 RATES

 Connect time on this service is free, at every baud rate, prime
 time and non-prime alike.  Prime time is 8:00 a.m. to 7:00 p.m.
 on weekdays; a "P" after the time at logon says you are in it.

 There is no membership support fee.

:DEFAULT TERMINAL PROFILE
=TERMINAL SETTINGS
 Your settings for this session are set with the SET command:

   SET BRIEF ON     brief "!" prompts (expert mode)
   SET BRIEF OFF    full prompts ("Enter choice !")
   SET PAGED ON     stop at each screen ("Press <CR> for more !")
   SET PAGED OFF    no stops (for offline readers)
   SET WIDTH n      the screen's width (40 to 132)
   SET LINES n      lines per screen, when paged

 Permanent settings are not kept yet: each logon starts with BRIEF
 OFF, PAGED OFF and WIDTH 80.

:LGN-1 SIGNUP JOIN PASSWORD
=CompuServe
 USER IDS

 Your User ID is your BBS account number written the CompuServe way,
 as two numbers with a comma between: account 1 is 72000,1.  It is
 shown at logon.  You may also type your BBS name at "User ID:".

 To sign up, call the BBS itself and make an account there; the same
 name and password let you in here.  Change your password on the
 BBS.

:ABOUT
=CompuServe
 ABOUT THIS SERVICE

 This is a recreation of the CompuServe Information Service as a
 terminal caller of the 1980s and 1990s saw it, running on this BBS.
 It is not affiliated with CompuServe.  The prompts and the shape of
 the menus follow the period's, so that old terminal programs and
 offline readers (TAPCIS, AutoSIG, OzCIS) can find their way.
